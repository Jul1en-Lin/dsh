# Triage labels

English | [中文](triage-labels.zh.md)

Engineering skills use five canonical triage roles. This file maps those roles to the labels used by this repository.

| Label in mattpocock/skills | Label in this tracker | Meaning                                   |
| -------------------------- | --------------------- | ----------------------------------------- |
| `needs-triage`             | `needs-triage`        | Maintainer needs to evaluate the issue    |
| `needs-info`               | `needs-info`          | Waiting for information from the reporter |
| `ready-for-agent`          | `ready-for-agent`     | Fully specified and ready for an AFK agent |
| `ready-for-human`          | `ready-for-human`     | Requires human implementation             |
| `wontfix`                  | `wontfix`             | Will not be actioned                       |

These operational labels coexist with the repository's [GitHub label taxonomy](../../.agents/notes/implemented/process/2026-08-08-unified-github-label-taxonomy.md).

When a skill names a triage role, use the corresponding tracker label from this table. Edit the right-hand column if the repository later changes its label names.
